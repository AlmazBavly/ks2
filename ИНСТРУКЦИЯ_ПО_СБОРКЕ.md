## Для разработчика: Детальная инструкция

### ⚠️ Важно: Перед сборкой

Убедитесь, что у вас установлен **Python 3.7 или выше**:
- Windows: https://www.python.org/downloads/
- macOS: обычно уже установлен, или `brew install python3`
- Linux: `sudo apt-get install python3` (Ubuntu/Debian)

### Windows

**Способ 1: Автоматический (рекомендуется)**

1. Дважды кликните на файл `СБОРКА_WINDOWS.bat`
   
   Или откройте командную строку (cmd) в папке проекта и запустите:
   ```cmd
   СБОРКА_WINDOWS.bat
   ```
   Скрипт автоматически:
   - Проверит наличие Python
   - Установит PyInstaller (если нужно)
   - Установит зависимости (если нужно)
   - Запустит сборку

**Способ 2: Вручную**

1. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   pip install pyinstaller
   ```

2. Запустите сборку:
   ```cmd
   python build_exe.py
   ```

**Результат:** Готовый файл будет в папке `dist/KS2Validator.exe`

### macOS/Linux

**Способ 1: Автоматический (рекомендуется)**

1. Откройте терминал в папке проекта
2. Сделайте скрипт исполняемым (если еще не сделано):
   ```bash
   chmod +x build.sh
   ```
3. Запустите:
   ```bash
   ./build.sh
   ```
   Скрипт автоматически:
   - Проверит наличие Python 3
   - Установит PyInstaller (если нужно)
   - Установит зависимости (если нужно)
   - Запустит сборку

**Способ 2: Вручную**

1. Установите зависимости:
   ```bash
   pip3 install -r requirements.txt
   pip3 install pyinstaller
   ```

2. Запустите сборку:
   ```bash
   python3 build_exe.py
   ```

**Результат:** Готовый файл будет в папке `dist/KS2Validator`

### 📋 Пошаговая инструкция (если автоматический способ не работает)

1. **Откройте терминал/командную строку** в папке проекта

2. **Проверьте Python:**
   ```bash
   python3 --version  # macOS/Linux
   python --version   # Windows
   ```
   Должно показать версию 3.7 или выше

3. **Установите зависимости:**
   ```bash
   pip3 install -r requirements.txt  # macOS/Linux
   pip install -r requirements.txt  # Windows
   ```

4. **Установите PyInstaller:**
   ```bash
   pip3 install pyinstaller  # macOS/Linux
   pip install pyinstaller   # Windows
   ```

5. **Запустите сборку:**
   ```bash
   python3 build_exe.py  # macOS/Linux
   python build_exe.py   # Windows
   ```

6. **Дождитесь завершения** (может занять 2-5 минут)

7. **Найдите готовый файл** в папке `dist/`

## ⚠️ Решение проблем при сборке

### Ошибка: "Python не найден"

**Решение:**
- Установите Python 3.7+ с официального сайта: https://www.python.org/downloads/
- При установке на Windows отметьте галочку "Add Python to PATH"

### Ошибка: "No module named 'PyInstaller'"

**Решение:**
```bash
pip3 install pyinstaller  # macOS/Linux
pip install pyinstaller   # Windows
```

### Ошибка: "No module named 'pandas'" или другие модули

**Решение:**
```bash
pip3 install -r requirements.txt  # macOS/Linux
pip install -r requirements.txt   # Windows
```

### Ошибка: "Permission denied" (macOS/Linux)

**Решение:**
```bash
chmod +x build.sh
./build.sh
```

Или используйте `python3 build_exe.py` напрямую

### Ошибка: "Command not found: python3" (macOS/Linux)

**Решение:**
Попробуйте `python` вместо `python3`, или установите Python 3:
```bash
brew install python3  # macOS
sudo apt-get install python3  # Linux
```

### Сборка занимает очень много времени

**Это нормально!** Сборка может занять 2-5 минут, так как:
- Упаковывается Python интерпретатор
- Упаковываются все библиотеки
- Создается один большой файл

### Файл получился очень большим (50-100 МБ)

**Это нормально!** Файл включает:
- Python интерпретатор (~20-30 МБ)
- Все библиотеки (pandas, openpyxl, flask и т.д.)
- Все зависимости

Это стандартный размер для портативных Python приложений.

### Сборка завершилась, но файл не запускается

**Проверьте:**
1. Файл находится в папке `dist/`
2. На macOS/Linux: дайте права на выполнение:
   ```bash
   chmod +x dist/KS2Validator
   ```
3. Попробуйте запустить из терминала, чтобы увидеть ошибки:
   ```bash
   ./dist/KS2Validator  # macOS/Linux
   dist\KS2Validator.exe  # Windows
   ```
