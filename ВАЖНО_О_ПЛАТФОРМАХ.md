# ⚠️ Важно: О совместимости исполняемых файлов

## ❌ НЕТ - .exe файл НЕ работает на всех ОС

**Файл `.exe` работает ТОЛЬКО на Windows!**

Исполняемые файлы, созданные PyInstaller, **платформо-специфичные**:
- ✅ `KS2Validator.exe` - работает **только на Windows**
- ✅ `KS2Validator.app` - работает **только на macOS**
- ✅ `KS2Validator` (без расширения) - работает **только на Linux**

**Нельзя создать один файл, который работает на всех ОС!**

## 🌍 Решения для всех ОС

### Вариант 1: Универсальный Python скрипт (работает везде) ⭐

**Файл `ЗАПУСТИТЬ.py` работает на всех ОС:**

```bash
python ЗАПУСТИТЬ.py  # Windows, macOS, Linux
```

**Требования:**
- Установлен Python 3.7+ на компьютере
- Скрипт автоматически установит зависимости

**Преимущества:**
- ✅ Один файл для всех ОС
- ✅ Автоматическая установка зависимостей
- ✅ Работает везде, где есть Python

**Недостатки:**
- ❌ Требует установленного Python

### Вариант 2: Отдельные исполняемые файлы для каждой ОС

**Для Windows:**
1. Соберите на Windows компьютере: дважды кликните `СБОРКА_WINDOWS.bat`
2. Получите: `dist\KS2Validator.exe`
3. Работает на любом Windows ПК без Python

**Для macOS:**
1. Соберите на Mac: дважды кликните `СБОРКА_MACOS.command` (откроется в терминале) или `./СБОРКА_MACOS.sh` в терминале
2. Получите: `dist/KS2Validator.app`
3. Работает на любом Mac без Python

**Для Linux:**
1. Соберите на Linux: `./СБОРКА_LINUX.sh`
2. Получите: `dist/KS2Validator`
3. Работает на любом Linux ПК без Python

## 📊 Сравнение вариантов

| Вариант | Работает на всех ОС | Требует Python | Размер |
|---------|---------------------|----------------|--------|
| `ЗАПУСТИТЬ.py` | ✅ Да | ✅ Да | ~1 КБ |
| `.exe` (Windows) | ❌ Только Windows | ❌ Нет | 50-100 МБ |
| `.app` (macOS) | ❌ Только macOS | ❌ Нет | 50-100 МБ |
| Исполняемый (Linux) | ❌ Только Linux | ❌ Нет | 50-100 МБ |

## 🎯 Рекомендации

### Если нужен один файл для всех ОС:
**Используйте `ЗАПУСТИТЬ.py`** - работает везде, где есть Python

### Если нужен файл без Python:
**Соберите отдельно для каждой ОС:**
- Windows → соберите на Windows → получите `.exe`
- macOS → соберите на macOS → получите `.app`
- Linux → соберите на Linux → получите исполняемый файл

## 💡 Почему так?

PyInstaller упаковывает:
- Python интерпретатор для конкретной ОС
- Библиотеки, скомпилированные для конкретной ОС
- Системные зависимости конкретной ОС

Поэтому нельзя создать один файл для всех ОС - каждая ОС имеет свою архитектуру и системные библиотеки.

## ✅ Итог

**`.exe` файл работает ТОЛЬКО на Windows!**

Для работы на всех ОС используйте:
- **`ЗАПУСТИТЬ.py`** - универсальный скрипт (требует Python)
- Или соберите отдельные файлы для каждой ОС
