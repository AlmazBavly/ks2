# Инструкция по использованию приложения проверки КС-2

## Для конечного пользователя

### Способ 1: Исполняемый файл (РЕКОМЕНДУЕТСЯ)

Если у вас есть готовый исполняемый файл `KS2Validator.exe` (Windows) или `KS2Validator` (macOS/Linux):

1. **Просто запустите файл двойным кликом**
2. Ничего устанавливать не нужно!
3. Приложение откроется и готово к работе

### Способ 2: Запуск через Python (для разработчиков)

**Windows:**
```cmd
python ks2_validator_web.py
```

**macOS/Linux:**
```bash
python3 ks2_validator_web.py
```

**Примечание:** Для этого способа нужно установить Python и зависимости (см. ниже).

## Первый запуск

При первом запуске приложение автоматически установит необходимые библиотеки (pandas, openpyxl).

Если возникнут ошибки, установите зависимости вручную:

```bash
pip install -r requirements.txt
```

или

```bash
pip3 install -r requirements.txt
```

## Использование

1. **Запустите приложение** одним из способов выше
2. **Загрузите файлы:**
   - Нажмите на область загрузки или перетащите файлы (Drag & Drop)
   - Выберите файл сметы (.xlsx или .xls)
   - Выберите файл КС-2 (.xlsx или .xls)
3. **Нажмите кнопку "Проверить соответствие"**
4. **Просмотрите результаты:**
   - **Сводка** - общая статистика проверки
   - **Детальная таблица результатов** с цветовой индикацией:
   - 🟢 **Зеленый** - все в порядке
   - 🔴 **Красный** - найдены превышения
   - 🟡 **Желтый** - предупреждения
6. **Экспортируйте отчет** - нажмите "📊 Экспорт в Excel"

## Требования

- Python 3.7 или выше
- Файлы должны быть в формате Excel (.xlsx или .xls)

## Решение проблем

### "Python не найден"
Установите Python с официального сайта: https://www.python.org/downloads/

### "No module named 'tkinter'"
**Windows:** Переустановите Python с галочкой "tcl/tk and IDLE"

**macOS:**
```bash
brew install python-tk
```

**Linux:**
```bash
sudo apt-get install python3-tk
```

### "No module named 'pandas'"
```bash
pip install pandas openpyxl
```
