📋 СМОТРИТЕ: КОМАНДЫ_СБОРКИ.md - все команды для каждой ОС!

⚠️ ВАЖНО: Для каждой ОС нужна своя сборка!
   - Windows → соберите на Windows → .exe
   - macOS → соберите на macOS → .app
   - Linux → соберите на Linux → исполняемый файл

═══════════════════════════════════════════════════════════
БЫСТРЫЕ КОМАНДЫ
═══════════════════════════════════════════════════════════

🪟 Windows:
   Дважды кликните: СБОРКА_WINDOWS.bat
   или в командной строке: СБОРКА_WINDOWS.bat

🍎 macOS:
   Дважды кликните: СБОРКА_MACOS.command
      (автоматически откроется в терминале)
   Или в терминале: ./СБОРКА_MACOS.sh

🐧 Linux:
   В терминале: ./СБОРКА_LINUX.sh

═══════════════════════════════════════════════════════════

ШАГ 4: ГОТОВЫЙ ФАЙЛ
═══════════════════════════════════════════════════════════

Готовый файл будет в папке:
   dist\KS2Validator.exe

Размер файла: 50-100 МБ (это нормально!)

═══════════════════════════════════════════════════════════
ИСПОЛЬЗОВАНИЕ
═══════════════════════════════════════════════════════════

1. Скопируйте KS2Validator.exe на USB-флешку
2. Запустите двойным кликом на любом Windows ПК
3. Браузер откроется автоматически
4. Ничего устанавливать не нужно!

ПРОБЛЕМЫ?
═══════════════════════════════════════════════════════════

"Python не найден" → Установите Python с python.org
"PyInstaller не найден" → pip install pyinstaller
"Зависимости не найдены" → pip install -r requirements.txt

Подробная инструкция: КАК_СОБРАТЬ_EXE.md
