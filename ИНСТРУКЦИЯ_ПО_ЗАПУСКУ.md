# Инструкция по запуску приложения

## 🌍 Универсальный способ (работает на всех ОС)

**Самый простой способ - используйте универсальный скрипт:**

```bash
python ЗАПУСТИТЬ.py
```

Или:

```bash
python3 ЗАПУСТИТЬ.py
```

Этот скрипт работает на **Windows, macOS и Linux** и автоматически:
- ✅ Проверяет Python
- ✅ Устанавливает зависимости (если нужно)
- ✅ Запускает приложение
- ✅ Открывает браузер

## 🖱️ Запуск двойным кликом мыши

### Windows

**Просто дважды кликните на файл:**
- `Запустить.bat` или `run_web.bat`

Приложение запустится автоматически, браузер откроется сам.

### macOS

**Дважды кликните на файл:**
- `Запустить.command`

Если система спрашивает разрешение, нажмите "Открыть".

**Альтернатива:** Можно также запустить `run_web.sh` двойным кликом.

### Linux

**Дважды кликните на файл:**
- `Запустить.sh`

## 📋 Что происходит при запуске

1. ✅ Проверяется наличие Python
2. ✅ Проверяются и устанавливаются зависимости (если нужно)
3. ✅ Запускается веб-сервер
4. ✅ Автоматически открывается браузер с интерфейсом

## 🌐 Адрес в браузере

После запуска приложение будет доступно по адресу:
```
http://127.0.0.1:5000
```

## ⚠️ Решение проблем

### "Не удается открыть, так как разработчик не может быть проверен" (macOS)

1. Откройте "Системные настройки" → "Безопасность"
2. Нажмите "Открыть в любом случае" рядом с сообщением о приложении
3. Или выполните в терминале:
   ```bash
   xattr -cr Запустить.command
   ```

### "Файл не запускается" (Linux)

Выполните в терминале:
```bash
chmod +x Запустить.sh
```

### "Python не найден"

Установите Python 3.7 или выше:
- **Windows:** https://www.python.org/downloads/
- **macOS:** `brew install python3` или скачайте с python.org
- **Linux:** `sudo apt-get install python3` (Ubuntu/Debian)

## 🛑 Остановка приложения

Закройте окно терминала, где запущено приложение, или нажмите `Ctrl+C` в этом окне.
