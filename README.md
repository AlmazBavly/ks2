# Сверка КС-2 со сметой

Портативное приложение для автоматической сверки формы КС-2 с локальной сметой.

## 🌍 Универсальный запуск на всех ОС

**Один скрипт работает на Windows, macOS и Linux:**

```bash
python ЗАПУСТИТЬ.py
```

Этот скрипт автоматически проверяет Python, устанавливает зависимости и запускает приложение!

## 🚀 Быстрый старт

### Для пользователя (готовый .exe файл) - ✅ Портативное приложение!

## 📊 Критерии проверки

Приложение выполняет полную сверку соответствия акта КС-2 локальной смете:

### 1. Объёмы работ
- Проверка соответствия объёмов в столбцах 6 (количество) и 8 (стоимость) КС-2 данным сметы
- Физические показатели (количество) в КС-2 **НЕ ДОЛЖНЫ превышать** показатели по смете
- Стоимостные показатели (стоимость) в КС-2 **НЕ ДОЛЖНЫ превышать** показатели по смете

### 2. Наименования работ
- Проверка идентичности наименований в столбце 3 КС-2 позициям в смете
- Выявление несоответствий в названиях работ

### 3. Единицы измерения
- Проверка соответствия единиц измерения в столбце 5 КС-2 единицам в смете

### 4. Расценки и стоимость
- Проверка корректности расценок в столбце 7 КС-2 (цена за единицу)
- Учет коэффициентов и индексов, указанных в смете
- Проверка соответствия стоимости в столбце 8 КС-2

### 5. Работы, не предусмотренные сметой
- Выявление позиций в КС-2, отсутствующих в смете
- Проверка, что все работы из КС-2 есть в смете

### 6. Реквизиты в шапке формы
- Проверка наличия обязательных реквизитов (названия организаций, коды ОКПО, номер договора)
- Примечание: для полной проверки соответствия договору требуется ручная сверка

### 7. Дублирование работ
- Выявление повторяющихся позиций при формировании нескольких актов
- Проверка уникальности работ в КС-2

### 8. Обработка дублей в смете
- Автоматическое обнаружение строк с одинаковыми номерами в графе 1
- Игнорирование строк с курсивным текстом в графе 1 при наличии дублей
- Использование только валидных строк для сверки

### 9. Детальная отчетность
- Все расхождения указываются с конкретными позициями в КС-2 и смете
- Детальное описание каждого несоответствия
- Адаптивная таблица результатов, полностью видимая на экране
- Экспорт в Excel с полной структурой таблицы

### Работа с интерфейсом

1. **Загрузите файлы:**
   - Нажмите на область загрузки или перетащите файлы (Drag & Drop)
   - Выберите файл сметы (.xlsx или .xls)
   - Выберите файл КС-2 (.xlsx или .xls)

2. **Нажмите "🔍 ПРОВЕРИТЬ"** - приложение автоматически сравнит файлы

3. **Просмотрите результаты:**
   - **Сводка** - общая статистика проверки
   - **Детальная таблица результатов** с цветовой индикацией:
     - 🟢 Зеленый - позиция соответствует смете
     - 🔴 Красный - превышение количества/стоимости или дублирование
     - 🟡 Желтый - несоответствия (наименования, единицы, расценки)
   - Таблица адаптивна и полностью видна на экране без горизонтальных скроллов
   - Все числовые значения отображаются полностью (не скрываются)

4. **Экспортируйте отчет** - нажмите "📊 Экспорт в Excel" для сохранения результатов
   - Экспортируемая таблица полностью соответствует интерфейсу
   - Включает все колонки: № КС-2, № сметы, Наименование, Обоснование, Ед., Количество (Смета/КС-2/Остаток), Цена (Смета/КС-2/Разн.), Стоимость (Смета/КС-2/Остаток), Статус

## ⚠️ Решение проблем

### Ошибка "Python не найден" (при сборке)
Установите Python с официального сайта: https://www.python.org/downloads/

### Ошибка "No module named 'tkinter'" (при сборке)
**Windows:** Переустановите Python с галочкой "tcl/tk and IDLE"

**macOS:**
```bash
brew install python-tk
```

**Linux:**
```bash
sudo apt-get install python3-tk
```

### Приложение не запускается
- Убедитесь, что файл не поврежден
- Попробуйте запустить от имени администратора (Windows)
- Проверьте антивирус (может блокировать .exe файлы)

### Приложение не находит данные в файлах
Убедитесь, что:
- Файлы имеют формат .xlsx или .xls
- Структура файлов соответствует стандартным форматам сметы и КС-2
- В файлах есть заголовки таблиц
