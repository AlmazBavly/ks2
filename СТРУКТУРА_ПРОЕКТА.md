# Структура проекта: Сверка КС-2 со сметой

Данный документ описывает основные рабочие файлы проекта и их назначение для анализа ИИ.

---

## 📁 Основные модули Python

### `ks2_validator.py`
**Назначение:** Основной модуль валидации и парсинга КС-2 и сметы

**Содержимое:**
- **Классы данных:**
  - `SmetaPosition` - структура позиции из сметы (номер, наименование, единица измерения, количество, цена, стоимость)
  - `KS2Position` - структура позиции из КС-2 (номер КС-2, номер по смете, наименование, обоснование, единица, количество, цена, стоимость)
  - `KS2Header` - реквизиты из шапки КС-2 (заказчик, подрядчик, объект, договор)
  - `ValidationResult` - результат проверки позиции (тип ошибки, сообщение, разницы, детали)

- **Enum:**
  - `IssueType` - типы несоответствий (превышение количества/стоимости/цены, отсутствие в смете, несоответствие единиц/наименований, дублирование)

- **Базовый класс:**
  - `Parser` - базовый класс для парсинга Excel файлов
    - Методы: `load()`, `find_header_row()`, `skip_graph_numbers_row()` - пропуск строк с номерами граф и разделов

- **Парсеры:**
  - `SmetaParser(Parser)` - парсит локальную смету из Excel
    - Метод `parse()` - извлекает позиции сметы в словарь по номеру позиции
    - Метод `_find_columns()` - определяет индексы колонок по заголовкам
    - Метод `_parse_row()` - парсит одну строку сметы
    - Фильтрует валидные позиции (требует заполненный № п/п, наименование, единицу, количество)

  - `KS2Parser(Parser)` - парсит форму КС-2 из Excel
    - Метод `parse()` - извлекает позиции КС-2 в список
    - Метод `parse_header()` - извлекает реквизиты из шапки КС-2
    - Метод `_find_columns()` - определяет индексы колонок (включая точное определение единицы измерения)
    - Метод `_parse_row()` - парсит одну строку КС-2
    - Пропускает строки "Раздел" и технические строки
    - Фильтрует только объекты `KS2Position`

- **Валидатор:**
  - `KS2Validator` - основной класс для проверки КС-2 против сметы
    - Конструктор: `__init__(ks2_positions, smeta_positions, ks2_header)`
    - Метод `validate()` - выполняет полную проверку:
      1. Проверка дублирования работ
      2. Проверка реквизитов шапки
      3. Сортировка позиций КС-2 по номеру
      4. Проверка каждой позиции по критериям
    - Метод `_validate_position()` - проверяет одну позицию:
      - Проверка наличия в смете
      - Проверка наименования (частичное совпадение)
      - Проверка обоснования
      - Проверка единицы измерения
      - Проверка превышения количества/цены/стоимости (с допусками)
      - Фиксация экономии (warnings)
    - Метод `_check_duplicates()` - проверка дублирования работ
    - Метод `_validate_header()` - проверка реквизитов шапки
    - Метод `get_summary()` - формирует сводку результатов
    - Вспомогательные методы: `_names_match()`, `_units_match()`, `safe_float()`

**Ключевые особенности:**
- Строгая фильтрация позиций (только валидные данные)
- Пропуск технических строк (номера граф, разделы)
- Точное определение колонок по заголовкам
- Многоуровневая защита от не-объектов в списках
- Допуски для сравнения (0.01 для количества/стоимости, 1% для цены)

### `ks2_validator_web.py`
**Назначение:** Веб-приложение Flask для интерактивной проверки КС-2

**Содержимое:**
- **Flask приложение:**
  - Инициализация Flask с поддержкой PyInstaller
  - Настройка загрузки файлов (макс. 50MB)
  - Временная директория для файлов

- **API endpoints:**
  - `GET /` - главная страница (рендерит `templates/index.html`)
  - `POST /api/validate` - валидация КС-2 и сметы
    - Принимает два файла (смета и КС-2)
    - Парсит файлы через `SmetaParser` и `KS2Parser`
    - Выполняет валидацию через `KS2Validator`
    - Возвращает JSON с результатами и сводкой
    - Форматирует результаты для фронтенда (включая warnings, severity, confidence)
  - `POST /api/export` - экспорт результатов в Excel
    - Создает Excel файл с результатами проверки
    - Применяет цветовое кодирование (зеленый/красный/желтый)
    - Автоподбор ширины колонок
  - `POST /api/shutdown` - остановка сервера
    - Устанавливает событие остановки
    - Останавливает сервер через `server.shutdown()`
    - Защита от повторных вызовов

- **Утилиты:**
  - `allowed_file()` - проверка расширения файла (.xlsx, .xls)
  - `find_free_port()` - поиск свободного порта (начиная с 5000)
  - `kill_process_on_port()` - остановка процесса на порту (macOS/Linux/Windows)
  - `open_browser()` - автоматическое открытие браузера после запуска сервера

- **Запуск сервера:**
  - Использует `make_server` из werkzeug для возможности программной остановки
  - Запускает сервер в отдельном потоке
  - Проверяет доступность сервера перед открытием браузера
  - Ожидает события остановки через `shutdown_event`
  - Graceful shutdown с защитой от повторных вызовов

**Ключевые особенности:**
- Автоматическое открытие браузера
- Автоматический поиск свободного порта
- Возможность остановки сервера через веб-интерфейс
- Поддержка экспорта результатов в Excel
- Обработка ошибок с детальным логированием

**Назначение:** Веб-интерфейс для загрузки файлов и отображения результатов

**Содержимое:**

- **JavaScript функциональность:**

**Ключевые особенности:**
- Drag-and-drop загрузка файлов

## 🔄 Поток данных

1. **Загрузка файлов** → `templates/index.html` (drag-and-drop)
2. **Отправка на сервер** → `POST /api/validate` в `ks2_validator_web.py`
3. **Парсинг сметы** → `SmetaParser.parse()` в `ks2_validator.py`
4. **Парсинг КС-2** → `KS2Parser.parse()` в `ks2_validator.py`
5. **Валидация** → `KS2Validator.validate()` в `ks2_validator.py`
6. **Форматирование результатов** → JSON ответ в `ks2_validator_web.py`
7. **Отображение** → JavaScript в `templates/index.html`
8. **Экспорт** → `POST /api/export` → Excel файл

## 🎯 Ключевые алгоритмы

### Парсинг Excel файлов
1. Поиск строки заголовков по ключевым словам
2. Определение индексов колонок по заголовкам (проверка 3 строк)
3. Пропуск строки с номерами граф (1, 2, 3...)
4. Пропуск строк "Раздел"
5. Фильтрация валидных позиций (заполненный № п/п, наименование, единица, количество)
6. Создание объектов `SmetaPosition` или `KS2Position`

### Валидация позиций
1. Сортировка позиций КС-2 по номеру
2. Для каждой позиции:
   - Поиск соответствующей позиции в смете по номеру
   - Проверка наименования (частичное совпадение)
   - Проверка единицы измерения
   - Проверка превышения количества/цены/стоимости (с допусками)
   - Фиксация экономии (warnings)
3. Формирование результатов с типами ошибок и деталями

### Обработка ошибок
- Фильтрация не-объектов из списков позиций
- Проверка типов перед доступом к атрибутам
- Безопасное преобразование типов (safe_float)
- Обработка исключений с детальным логированием

## 📝 Примечания для ИИ

- Все парсеры наследуются от базового класса `Parser`
- Используется строгая фильтрация для предотвращения парсинга технических строк
- Многоуровневая защита от попадания не-объектов в списки позиций
- Веб-приложение использует Flask с возможностью программной остановки
- Интерфейс полностью адаптивный и поддерживает drag-and-drop
- Результаты валидации включают детальную информацию для пользователя
