# 📁 Структура файлов проекта

## ✅ Актуальные файлы (нужны для работы)

### Основные модули
- `ks2_validator.py` - Основная логика парсинга и валидации
- `ks2_validator_web.py` - Веб-приложение (Flask)
- `ЗАПУСТИТЬ.py` - **Универсальный скрипт запуска для всех ОС** ⭐

### Интерфейс
- `templates/index.html` - Веб-интерфейс

### Скрипты запуска (для удобства)
- `Запустить.bat` - Запуск на Windows (двойной клик)
- `Запустить.command` - Запуск на macOS (двойной клик)
- `Запустить.sh` - Запуск на Linux (двойной клик)
- `run_web.bat` - Запуск на Windows (через командную строку)
- `run_web.sh` - Запуск на macOS/Linux (через терминал)

### Скрипты сборки
- `build_exe.py` - Скрипт сборки исполняемого файла
- `СБОРКА_WINDOWS.bat` - **Сборка для Windows** (дважды кликните для запуска) ⭐
- `СБОРКА_MACOS.command` - **Сборка для macOS** (дважды кликните - откроется в терминале) ⭐
- `СБОРКА_MACOS.sh` - **Сборка для macOS** (запуск в терминале: `./СБОРКА_MACOS.sh`) ⭐
- `СБОРКА_LINUX.sh` - **Сборка для Linux** (запуск: `./СБОРКА_LINUX.sh`) ⭐
- `build.bat` - Старый файл (для обратной совместимости, используйте `СБОРКА_WINDOWS.bat`)
- `build.sh` - Старый файл (для обратной совместимости, используйте `СБОРКА_MACOS.sh` или `СБОРКА_LINUX.sh`)

### Скрипты управления зависимостями
- `ОБНОВИТЬ_ЗАВИСИМОСТИ.bat` - **Обновление зависимостей для Windows** ⭐
- `ОБНОВИТЬ_ЗАВИСИМОСТИ.sh` - **Обновление зависимостей для macOS/Linux** ⭐
- `ОБНОВИТЬ_ЗАВИСИМОСТИ.command` - **Обновление зависимостей для macOS** (дважды кликните) ⭐
- `venv/` - Папка с виртуальным окружением (создается автоматически, не в git)
- `requirements.txt` - Список зависимостей проекта
- `requirements-lock.txt` - Точные версии зависимостей (создается автоматически)

### Тесты
- `tests/` - Папка с тестами
  - `__init__.py`
  - `test_validator.py`
  - `test_web.py`
- `run_tests.sh` - Запуск тестов

### Зависимости и документация
- `requirements.txt` - Список зависимостей Python
- `README.md` - Главная документация
- `ИНСТРУКЦИЯ.md` - Подробная инструкция по использованию
- `ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.md` - Инструкция по запуску
- `ИНСТРУКЦИЯ_ПО_СБОРКЕ.md` - Инструкция по сборке
- `СТРУКТУРА_ПРОЕКТА.md` - Структура проекта
- `УНИВЕРСАЛЬНЫЙ_ЗАПУСК.md` - Инструкция по универсальному запуску

### Результаты сборки
- `dist/` - Папка с собранными исполняемыми файлами
  - `KS2Validator.exe` (Windows) - после сборки на Windows
  - `KS2Validator.app` (macOS) - после сборки на macOS
  - `KS2Validator` (Linux) - после сборки на Linux

## 🗑️ Удаленные файлы (не нужны)

Следующие файлы были удалены как неактуальные:
- Отладочные скрипты (debug_smeta.py, test_parser_debug.py и т.д.)
- Старые документационные файлы
- Временные файлы сборки (build/)
- Лог файлы
- Дублирующие инструкции

## 🚀 Рекомендуемый способ запуска

**Для всех ОС используйте универсальный скрипт:**

```bash
python ЗАПУСТИТЬ.py
```

Этот скрипт работает на Windows, macOS и Linux!
