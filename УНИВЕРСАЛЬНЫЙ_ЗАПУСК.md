# 🌍 Универсальный запуск на всех операционных системах

## ✅ Один скрипт для всех ОС!

Файл **`ЗАПУСТИТЬ.py`** работает на **любой операционной системе**:
- ✅ Windows
- ✅ macOS
- ✅ Linux

## 🚀 Как запустить

### Способ 1: Через Python (универсальный)

**На любой ОС:**

```bash
python ЗАПУСТИТЬ.py
```

Или:

```bash
python3 ЗАПУСТИТЬ.py
```

### Способ 2: Двойной клик (для каждой ОС)

**Windows:**
- Дважды кликните на `Запустить.bat`

**macOS:**
- Дважды кликните на `Запустить.command`

**Linux:**
- Дважды кликните на `Запустить.sh`

## ✨ Что делает универсальный скрипт

1. ✅ **Проверяет версию Python** (требуется 3.7+)
2. ✅ **Проверяет зависимости** (pandas, openpyxl, flask, werkzeug)
3. ✅ **Автоматически устанавливает** недостающие зависимости
4. ✅ **Запускает веб-сервер**
5. ✅ **Автоматически открывает браузер**

## 📋 Требования

- **Python 3.7 или выше** (установлен на компьютере)
- **Доступ в интернет** (для установки зависимостей при первом запуске)

## 🔄 Первый запуск

При первом запуске скрипт автоматически установит все необходимые зависимости:

```
⚠️  Обнаружены отсутствующие зависимости:
   - pandas
   - openpyxl
   - flask
   - werkzeug

Установка зависимостей...
✅ Зависимости установлены!
```

Это займет 1-2 минуты. При последующих запусках установка не потребуется.

## 💡 Преимущества универсального скрипта

- ✅ **Один файл для всех ОС** - не нужно разные скрипты
- ✅ **Автоматическая установка зависимостей** - не нужно устанавливать вручную
- ✅ **Проверка версии Python** - предупреждает о проблемах
- ✅ **Работает везде** - Windows, macOS, Linux

## ⚠️ Важно

Универсальный скрипт требует установленного Python на компьютере.

Если нужен **полностью портативный вариант без Python**, используйте собранные исполняемые файлы:
- Windows: `dist/KS2Validator.exe` (соберите на Windows)
- macOS: `dist/KS2Validator.app` (соберите на macOS)
- Linux: `dist/KS2Validator` (соберите на Linux)

## 🆘 Решение проблем

### Ошибка: "Python не найден"

**Решение:**
- Установите Python 3.7+ с https://www.python.org/downloads/
- При установке на Windows отметьте "Add Python to PATH"

### Ошибка: "No module named 'pandas'"

**Решение:**
Скрипт должен установить зависимости автоматически. Если не получилось:

```bash
pip install -r requirements.txt
```

### Ошибка: "Permission denied" (macOS/Linux)

**Решение:**
```bash
chmod +x ЗАПУСТИТЬ.py
python3 ЗАПУСТИТЬ.py
```
