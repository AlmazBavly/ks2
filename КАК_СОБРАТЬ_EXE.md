# 🚀 Как собрать один исполняемый файл

## 🚀 Быстрый старт

**См. файл `КОМАНДЫ_СБОРКИ.md` для готовых команд запуска!**

---

## ⚠️ Важно

**Для каждой ОС нужна своя сборка!**

- **Windows** → соберите на Windows → получите `.exe`
- **macOS** → соберите на macOS → получите `.app`
- **Linux** → соберите на Linux → получите исполняемый файл

**❗ ВАЖНО: `.exe` файл работает ТОЛЬКО на Windows!**

- ❌ НЕ работает на macOS
- ❌ НЕ работает на Linux
- ✅ Работает ТОЛЬКО на Windows

Для работы на всех ОС используйте универсальный скрипт `ЗАПУСТИТЬ.py` (см. файл `УНИВЕРСАЛЬНЫЙ_ЗАПУСК.md`)

## 📋 Команды сборки

**См. подробные команды в файле: `КОМАНДЫ_СБОРКИ.md`**

### Windows
```
Дважды кликните: СБОРКА_WINDOWS.bat
```
или в командной строке:
```cmd
СБОРКА_WINDOWS.bat
```

### macOS
```
Дважды кликните: СБОРКА_MACOS.command
```
(Автоматически откроется в терминале)
или в терминале:
```bash
./СБОРКА_MACOS.sh
```

### Linux
```bash
./СБОРКА_LINUX.sh
```

---

## 📋 Что получится

После сборки вы получите **один файл** (50-100 МБ), который:
- ✅ Работает на любом компьютере с той же ОС
- ✅ Работает с USB-флешки
- ✅ Не требует установки Python
- ✅ Не требует установки библиотек
- ✅ Все зависимости уже включены в файл

## 🛠️ Пошаговая инструкция сборки

### Шаг 1: Подготовка

1. **Скопируйте всю папку проекта** на компьютер нужной ОС
2. **Установите Python 3.7+**:
   - Windows: https://www.python.org/downloads/ (отметьте "Add Python to PATH")
   - macOS: обычно уже установлен, или `brew install python3`
   - Linux: `sudo apt-get install python3`
3. **Откройте командную строку/терминал** в папке проекта

### Шаг 2: Запуск сборки

**Способ 1: Автоматический (самый простой)** ⭐

**Windows:**
```
Дважды кликните: СБОРКА_WINDOWS.bat
```

**macOS:**
```
Дважды кликните: СБОРКА_MACOS.sh
```

**Linux:**
```bash
./СБОРКА_LINUX.sh
```

Скрипт автоматически:
- Проверит Python
- Установит PyInstaller (если нужно)
- Установит зависимости (если нужно)
- Запустит сборку

**Способ 2: Вручную**

1. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   pip install pyinstaller
   ```
   (или `pip3` на macOS/Linux)

2. Запустите сборку:
   ```cmd
   python build_exe.py
   ```
   (или `python3 build_exe.py` на macOS/Linux)

### Шаг 3: Ожидание

Сборка займет **2-5 минут**. Вы увидите процесс в командной строке.

### Шаг 4: Готовый файл

После завершения сборки файл будет здесь:
```
dist\KS2Validator.exe
```

## 📦 Использование готового .exe

1. **Скопируйте файл** `KS2Validator.exe` на USB-флешку или любой компьютер
2. **Запустите двойным кликом** - работает откуда угодно!
3. **Браузер откроется автоматически** с интерфейсом приложения
4. **Ничего устанавливать не нужно!**

## ⚠️ Решение проблем

### Ошибка: "Python не найден"

**Решение:**
- Переустановите Python с галочкой "Add Python to PATH"
- Или используйте полный путь: `C:\Python3x\python.exe build_exe.py`

### Ошибка: "No module named 'PyInstaller'"

**Решение:**
```cmd
pip install pyinstaller
```

### Ошибка: "No module named 'pandas'"

**Решение:**
```cmd
pip install -r requirements.txt
```

### Антивирус блокирует сборку

**Решение:**
- Добавьте папку проекта в исключения антивируса
- Или временно отключите антивирус на время сборки

### Файл получился очень большим (50-100 МБ)

**Это нормально!** Файл включает:
- Python интерпретатор (~20-30 МБ)
- Все библиотеки (pandas, openpyxl, flask)
- Все зависимости

## 💡 Советы

1. **Первый запуск** может быть медленнее - это нормально
2. **Размер файла** большой, но это стандартно для портативных Python приложений
3. **Антивирус** может предупреждать - это нормально, добавьте в исключения
4. **Права администратора** не требуются для запуска

## 📝 Что происходит при сборке

PyInstaller:
1. Анализирует код и находит все зависимости
2. Упаковывает Python интерпретатор
3. Упаковывает все библиотеки
4. Включает шаблоны HTML
5. Создает один .exe файл
