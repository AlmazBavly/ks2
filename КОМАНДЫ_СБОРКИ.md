# 🚀 Команды для сборки исполняемого файла

## ⚠️ Важно

**Для каждой операционной системы нужна своя сборка!**

- Windows → соберите на Windows → получите `.exe`
- macOS → соберите на macOS → получите `.app`
- Linux → соберите на Linux → получите исполняемый файл

## 📋 Команды сборки

### 🪟 Windows

**Способ 1: Дважды кликните на файл (самый простой)** ⭐
```
СБОРКА_WINDOWS.bat
```

**Способ 2: Через командную строку**
```cmd
СБОРКА_WINDOWS.bat
```

**Способ 3: Через Python**
```cmd
python build_exe.py
```

**Способ 4: Вручную (если автоматический не работает)**
```cmd
pip install -r requirements.txt
pip install pyinstaller
python build_exe.py
```

**Результат:** `dist\KS2Validator.exe`

---

### 🍎 macOS

**Способ 1: Дважды кликните на файл (самый простой)** ⭐
```
СБОРКА_MACOS.command
```
(Автоматически откроется в терминале)

**Способ 2: Через терминал**
```bash
./СБОРКА_MACOS.sh
```
или
```bash
./СБОРКА_MACOS.command
```

**Способ 3: Через Python**
```bash
python3 build_exe.py
```

**Способ 4: Вручную (если автоматический не работает)**
```bash
pip3 install -r requirements.txt
pip3 install pyinstaller
python3 build_exe.py
```

**Результат:** `dist/KS2Validator.app` и `dist/KS2Validator`

---

### 🐧 Linux

**Способ 1: Через терминал (рекомендуется)** ⭐
```bash
./СБОРКА_LINUX.sh
```

**Способ 2: Через Python**
```bash
python3 build_exe.py
```

**Способ 3: Вручную (если автоматический не работает)**
```bash
pip3 install -r requirements.txt
pip3 install pyinstaller
python3 build_exe.py
```

**Результат:** `dist/KS2Validator`

## 📝 Быстрая справка

### Перед первой сборкой:
1. ✅ Установлен Python 3.7+
2. ✅ Запустите скрипт обновления зависимостей:
   - Windows: `ОБНОВИТЬ_ЗАВИСИМОСТИ.bat`
   - macOS: `./ОБНОВИТЬ_ЗАВИСИМОСТИ.sh` или дважды кликните `ОБНОВИТЬ_ЗАВИСИМОСТИ.command`
   - Linux: `./ОБНОВИТЬ_ЗАВИСИМОСТИ.sh`
3. ✅ Это создаст виртуальное окружение `venv/` со всеми зависимостями

### При последующих сборках:
- ✅ Скрипты сборки автоматически используют `venv/`
- ✅ Если `venv/` не найден, он будет создан автоматически

### После сборки:
- ✅ Готовый файл в папке `dist/`
- ✅ Размер файла: 50-100 МБ (это нормально!)
- ✅ Можно копировать на USB-флешку и использовать на любой машине с той же ОС

### Если сборка не запускается:
1. Проверьте Python: `python --version` (Windows) или `python3 --version` (macOS/Linux)
2. Установите зависимости: `pip install -r requirements.txt` (Windows) или `pip3 install -r requirements.txt` (macOS/Linux)
3. Установите PyInstaller: `pip install pyinstaller` (Windows) или `pip3 install pyinstaller` (macOS/Linux)
4. Запустите сборку:
   - Windows: дважды кликните `СБОРКА_WINDOWS.bat`
   - macOS: `./СБОРКА_MACOS.sh` или дважды кликните файл
   - Linux: `./СБОРКА_LINUX.sh`
