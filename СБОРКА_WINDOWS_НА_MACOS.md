# Сборка Windows .exe на macOS

## ⚠️ Важно: PyInstaller не поддерживает кросс-компиляцию

PyInstaller создает исполняемые файлы только для той платформы, на которой он запущен. Это означает, что для сборки Windows `.exe` файла вам нужна Windows.

## 🎯 Рекомендуемые способы

### 1. GitHub Actions (САМЫЙ ПРОСТОЙ) ⭐

Автоматическая сборка на Windows в облаке - бесплатно и без установки Windows!

#### Шаг 1: Запустите скрипт

```bash
./СБОРКА_WINDOWS_С_MACOS.sh
```

Выберите вариант **1** - скрипт создаст файл `.github/workflows/build-windows.yml`

#### Шаг 2: Загрузите на GitHub

```bash
git add .github/workflows/build-windows.yml
git commit -m "Add Windows build workflow"
git push
```

#### Шаг 3: Запустите сборку

1. Перейдите на GitHub → вкладка **Actions**
2. Найдите workflow **"Build Windows Executable"**
3. Нажмите **"Run workflow"**
4. Выберите ветку и нажмите **"Run"**

#### Шаг 4: Скачайте готовый .exe

1. Дождитесь завершения сборки (2-5 минут)
2. Нажмите на завершенный workflow
3. Прокрутите вниз до секции **"Artifacts"**
4. Скачайте **KS2Validator-Windows.zip**
5. Распакуйте - внутри будет `KS2Validator.exe`

**Преимущества:**
- ✅ Бесплатно
- ✅ Не требует установки Windows
- ✅ Автоматическая сборка при каждом push
- ✅ Готовый .exe можно скачать в любой момент

### 2. Виртуальная машина Windows (НАДЕЖНО)

Если у вас есть виртуальная машина Windows, это самый надежный способ.

#### Варианты виртуальных машин:

**Parallels Desktop** (платно, ~$100/год)
- Самый быстрый и удобный для macOS
- Отличная интеграция с macOS
- [Скачать](https://www.parallels.com/products/desktop/)

**VMware Fusion** (платно, ~$80)
- Хорошая производительность
- [Скачать](https://www.vmware.com/products/fusion.html)

**VirtualBox** (бесплатно)
- Медленнее, но бесплатно
- [Скачать](https://www.virtualbox.org/)

#### Инструкция:

1. **Установите виртуальную машину** (выберите одну из выше)

2. **Установите Windows** на виртуальную машину
   - Скачайте Windows 10/11 ISO с официального сайта Microsoft
   - Создайте виртуальную машину и установите Windows

3. **Скопируйте проект** на виртуальную машину:
   - Через общую папку (Parallels/VMware)
   - Или через `git clone` внутри Windows
   - Или через USB-накопитель

4. **В Windows выполните:**
   ```cmd
   СБОРКА_WINDOWS.bat
   ```
   
   Или:
   ```cmd
   python build_exe.py
   ```

5. **Скопируйте готовый .exe** обратно на macOS через общую папку

**Преимущества:**
- ✅ 100% надежность
- ✅ Полный контроль над процессом
- ✅ Можно тестировать .exe сразу

**Недостатки:**
- ❌ Требует установки Windows
- ❌ Требует много места на диске (~20-50 ГБ)
- ❌ Может быть медленно на слабых компьютерах

### 3. Wine (ЭКСПЕРИМЕНТАЛЬНО) ⚠️

Wine позволяет запускать Windows приложения на macOS, но сборка через Wine часто не работает из-за сложных библиотек (pandas, numpy).

#### Установка Wine:

```bash
brew install --cask wine-stable
```

#### Установка Python для Windows в Wine:

1. Скачайте Python для Windows: https://www.python.org/downloads/
2. Установите через Wine:
   ```bash
   wine python-3.11.x.exe
   ```
3. Следуйте инструкциям установщика

#### Запуск сборки:

```bash
./СБОРКА_WINDOWS_С_MACOS.sh
```

Выберите вариант **3** - скрипт попытается собрать через Wine.

**⚠️ ВАЖНО:** 
- Wine может создать нерабочий .exe
- Обязательно проверьте файл на реальном Windows
- Многие библиотеки Python не работают в Wine

## ❓ Часто задаваемые вопросы

### Почему нельзя просто собрать .exe на macOS?

PyInstaller упаковывает Python интерпретатор и библиотеки, которые скомпилированы для конкретной операционной системы. Windows использует другой формат исполняемых файлов (PE), чем macOS (Mach-O).

### Какой способ лучше?

**Для большинства случаев:** GitHub Actions
- Бесплатно
- Не требует установки Windows
- Автоматическая сборка

**Если нужен полный контроль:** Виртуальная машина
- 100% надежность
- Можно тестировать сразу

**Если нет доступа к интернету:** Виртуальная машина или Wine

### Можно ли использовать Docker?

Docker на macOS не может запускать Windows контейнеры. Windows контейнеры требуют Windows хост-систему.

### Сколько времени занимает сборка?

- GitHub Actions: 2-5 минут
- Виртуальная машина: 2-5 минут (после установки)
- Wine: 5-10 минут (и может не сработать)

## 🔧 Решение проблем

### GitHub Actions не запускается

Проверьте:
1. Файл `.github/workflows/build-windows.yml` существует
2. Проект загружен на GitHub
3. У вас есть права на репозиторий

### Виртуальная машина работает медленно

- Увеличьте количество RAM для виртуальной машины (минимум 4 ГБ)
- Увеличьте количество CPU ядер
- Используйте SSD вместо HDD

### Wine не работает

Wine часто не может собрать Python приложения с pandas/numpy. Используйте GitHub Actions или виртуальную машину.
